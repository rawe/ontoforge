# Working notes: read operations

Temporary. These are working documents for one piece of ongoing design work, not
documentation of the system.

They live here rather than under `docs/` on purpose. `docs/` describes the system as it is
and holds no analysis, no open questions and no proposals. These three documents are all
three of those things.

| File | What it is |
|---|---|
| [goal.md](goal.md) | What this work is about and what we want at the end |
| [approach.md](approach.md) | How we plan to proceed and in which order we decide |
| [inventory.md](inventory.md) | Every read operation that exists today, and where the three interfaces disagree |

When the work is finished, whatever is decided moves into `docs/` — the rules into
`docs/decisions.md`, the changed surface into `docs/interfaces.md` and the capability
documents — and this directory is deleted.
